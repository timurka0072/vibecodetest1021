# 🚀 Быстрый старт IP Manager

## Установка (один раз)

1. **Установите Node.js** (если ещё не установлен)
   - Скачайте с https://nodejs.org/
   - Установите, следуя инструкциям

2. **Установите зависимости**
   ```bash
   npm install
   ```

## Запуск системы

### Вариант 1: Автоматический запуск (рекомендуется)

**Windows:**
```bash
start.bat
```

**macOS/Linux:**
```bash
chmod +x start.sh
./start.sh
```

### Вариант 2: Ручной запуск

**Терминал 1 - Сервер базы данных:**
```bash
node server/init-db.js  # Только при первом запуске
node server/server.js
```

**Терминал 2 - Веб-интерфейс:**
```bash
npm run dev
```

## Открыть приложение

Откройте браузер: **http://localhost:5173**

## Доступ для других пользователей

1. Узнайте IP-адрес вашего компьютера:
   - Windows: `ipconfig` → IPv4-адрес
   - macOS/Linux: `ifconfig` или `ip addr`

2. Отредактируйте файл `src/api.ts`:
   ```typescript
   const API_BASE_URL = 'http://<ВАШ_IP>:3001/api';
   ```

3. Пересоберите проект:
   ```bash
   npm run build
   ```

4. Раздайте папку `dist/` другим пользователям или запустите `npm run dev` на их компьютерах

## Структура данных

Все данные хранятся в файле: **`server/ip_manager.db`**

Для резервного копирования просто скопируйте этот файл.
