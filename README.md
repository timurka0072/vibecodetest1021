# IP Manager - Система учёта IP-адресов

Полноценная система для учёта IP-адресов, устройств и сотрудников в организации с централизованной базой данных.

## 🚀 Возможности

- **Управление IP-адресами** - учёт всех IP-адресов в сети
- **Справочник сотрудников** - база данных сотрудников с автоподстановкой
- **Учёт устройств** - привязка устройств (ноутбуки, ПК, принтеры, МФУ) к IP-адресам
- **Множественные назначения** - несколько сотрудников могут работать на одном IP
- **Электронные подписи (ЭЦП)** - учёт и мониторинг сроков действия
- **Настраиваемые сети** - поддержка нескольких IP-сетей с разными масками
- **Отчёты и экспорт** - генерация отчётов и экспорт в CSV
- **Централизованная база данных** - все пользователи работают с общими данными

## 📋 Требования

- **Node.js** версии 18 или выше
- **npm** (устанавливается вместе с Node.js)

### Установка Node.js

1. Скачайте Node.js с официального сайта: https://nodejs.org/
2. Установите, следуя инструкциям установщика
3. Проверьте установку:
   ```bash
   node --version
   npm --version
   ```

## 🛠️ Установка и запуск

### 1. Установка зависимостей

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

### 2. Инициализация базы данных

Создайте базу данных с начальными данными:

```bash
node server/init-db.js
```

Это создаст:
- Файл базы данных `server/ip_manager.db`
- Сеть по умолчанию (192.168.1.0/24)
- 254 IP-адреса в пуле

### 3. Запуск сервера базы данных

В первом терминале запустите backend сервер:

```bash
node server/server.js
```

Вы увидите:
```
╔═══════════════════════════════════════════════════════════╗
║                                                           ║
║   🚀 IP Manager API Server                                ║
║                                                           ║
║   Server running on:                                      ║
║   • Local:   http://localhost:3001                        ║
║   • Network: http://192.168.1.100:3001                    ║
║                                                           ║
║   Database: SQLite (ip_manager.db)                        ║
║                                                           ║
╚═══════════════════════════════════════════════════════════╝
```

**Важно:** Запомните IP-адрес вашей сети (Network) - он понадобится другим пользователям!

### 4. Запуск веб-интерфейса

Во втором терминале запустите фронтенд:

```bash
npm run dev
```

Откройте браузер и перейдите по адресу: **http://localhost:5173**

## 🌐 Доступ для других пользователей

Чтобы другие пользователи могли работать с системой:

### На компьютере администратора (где запущен сервер):

1. Узнайте IP-адрес вашего компьютера:
   - **Windows:** `ipconfig` → найдите "IPv4-адрес"
   - **macOS/Linux:** `ifconfig` или `ip addr`

2. Убедитесь, что сервер запущен и доступен по адресу `http://<ВАШ_IP>:3001`

### На компьютерах пользователей:

1. Откройте файл `src/api.ts`
2. Измените строку:
   ```typescript
   const API_BASE_URL = 'http://localhost:3001/api';
   ```
   на:
   ```typescript
   const API_BASE_URL = 'http://<IP_АДМИНИСТРАТОРА>:3001/api';
   ```
   
   Например:
   ```typescript
   const API_BASE_URL = 'http://192.168.1.100:3001/api';
   ```

3. Пересоберите проект:
   ```bash
   npm run build
   ```

4. Раздайте пользователям папку `dist/` или запустите:
   ```bash
   npm run dev
   ```

### Настройка брандмауэра (если нужно)

Если другие пользователи не могут подключиться, откройте порт 3001:

**Windows:**
```powershell
netsh advfirewall firewall add rule name="IP Manager API" dir=in action=allow protocol=TCP localport=3001
```

**Linux (Ubuntu/Debian):**
```bash
sudo ufw allow 3001/tcp
```

**macOS:**
Системные настройки → Защита и безопасность → Брандмауэр → Добавить разрешение для Node.js

## 🔧 Настройка

### Изменение порта сервера

Отредактируйте `server/server.js`:
```javascript
const PORT = process.env.PORT || 3001; // Измените 3001 на нужный порт
```

### Изменение адреса API

Отредактируйте `src/api.ts`:
```typescript
const API_BASE_URL = 'http://localhost:3001/api'; // Измените на нужный адрес
```

### Резервное копирование базы данных

База данных хранится в файле `server/ip_manager.db`. Для резервного копирования просто скопируйте этот файл.

## 📊 Использование

### 1. Настройка сетей

Перейдите в раздел **Настройки** → **Сети** и добавьте ваши IP-сети:
- Название сети
- Сетевой адрес (например, 192.168.1.0)
- Маска подсети (например, /24)
- Диапазон IP-адресов

### 2. Добавление сотрудников

Перейдите в раздел **Сотрудники** и добавьте всех сотрудников:
- ФИО
- Должность
- Отдел
- Email и телефон

### 3. Назначение IP-адресов

Перейдите в раздел **Пул IP-адресов**:
- Выберите свободный IP-адрес
- Нажмите "Редактировать"
- Добавьте устройства (ноутбук, принтер и т.д.)
- Добавьте сотрудников, которые будут использовать этот IP
- Укажите кабинет и дату назначения

### 4. Учёт ЭЦП

Перейдите в раздел **ЭЦП** и добавьте электронные подписи:
- ФИО владельца
- Удостоверяющий центр
- Серийный номер
- Даты выдачи и окончания срока действия

Система автоматически рассчитает статус (активна/истекает/просрочена).

### 5. Отчёты

Перейдите в раздел **Отчёты** для:
- Просмотра свободных IP-адресов
- Отчётов по кабинетам
- Отчётов по сотрудникам
- Списка истекающих ЭЦП
- Экспорта данных в CSV

## 🐛 Решение проблем

### Ошибка "Failed to fetch"

**Причина:** Сервер не запущен или недоступен

**Решение:**
1. Убедитесь, что сервер запущен: `node server/server.js`
2. Проверьте правильность адреса в `src/api.ts`
3. Проверьте брандмауэр

### База данных не создаётся

**Причина:** Нет прав на запись в папку `server/`

**Решение:** Запустите команду от имени администратора или измените права доступа к папке.

### Другие пользователи не могут подключиться

**Причина:** Брандмауэр блокирует подключение

**Решение:** Откройте порт 3001 в брандмауэре (см. раздел "Настройка брандмауэра")
